### Added
#### Profiles
- Added `physical_site` profile carrying physical site context through the `physical_site` object, attached to the Identity & Access Management and Findings classes, and to the `location` object so devices, endpoints, and persons carry site context through `location`.
#### Objects
- Added `physical_site` object describing a physical site as defined by the reporting organization (`uid`, `name`) and the location within it (`building`, `floor`, `site_zone`).
- Added `site_zone` object describing a defined area within a physical site that shares a common security posture, distinct from the network `zone` attribute. It reuses `type_id` with an object-scoped enum: Unknown (0), Perimeter (1), Public (2), Restricted (3), Critical (4), Transitional (5), External (6), Other (99), with `type` as its sibling.
#### Dictionary Attributes
- Added `building` and `floor` as `string_t` physical site attributes.
- Added `physical_site` and `site_zone` as object attributes and `is_armed` as a `boolean_t`.

### Improved
#### Objects
- Added `physical_site` to the `location` object's `at_least_one` constraint, so a location that carries only physical site context validates when the `physical_site` profile is applied.
