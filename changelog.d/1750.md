### Added
#### Profiles
- Added `physical_site` profile carrying physical site context (`site_uid`, `site_name`, `building`, `floor`, `site_zone`), attached to the Identity & Access Management and Findings classes, and to the `location` object so devices, endpoints, and persons carry site context through `location`.
#### Objects
- Added `site_zone` object describing a defined area within a physical site that shares a common security posture, distinct from the network `zone` attribute. It reuses `type_id` with an object-scoped enum: Unknown (0), Perimeter (1), Public (2), Restricted (3), Critical (4), Transitional (5), External (6), Other (99), with `type` as its sibling.
#### Dictionary Attributes
- Added `site_uid`, `site_name`, `building`, and `floor` as `string_t` physical site context attributes.
- Added `site_zone` as an object attribute and `is_armed` as a `boolean_t`.

### Improved
#### Objects
- Added `site_uid` to the `location` object's `at_least_one` constraint, so a location that carries only physical site context validates when the `physical_site` profile is applied.
