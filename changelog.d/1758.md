### Added
#### Categories
- Added `Physical Security` category (uid 9) for activity in the physical world: portal and access control activity, alarm signals and their disposition, guard patrols, post staffing, response dispatch, and physical security reports.
#### Event Classes
- Added `Physical Access Activity` (9001) event class to the Physical Security category: door-side outcomes and portal state changes (the access decision itself is an Authentication event carrying the `physical_site` profile), following the ONVIF Access Control and Door Control service vocabularies.
- Added `Alarm Signal Activity` (9002) event class to the Physical Security category: alarm signals from monitored points, crosswalked to SIA DC-03 and Contact ID (SIA DC-05).
- Added `Alarm Disposition Activity` (9003) event class to the Physical Security category: the validated outcome of a signal, with ANSI/TMA AVS-01 validation levels.
- Added `Patrol Activity` (9004) event class to the Physical Security category: guard tours, checkpoint registrations, and their exceptions.
- Added `Post Staffing Activity` (9005) event class to the Physical Security category: post assumption, relief, no-shows, and coverage gaps.
- Added `Response Activity` (9006) event class to the Physical Security category: dispatch and progress of a response resource through assigned, en route, on scene, and cleared.
- Added `Physical Report Activity` (9007) event class to the Physical Security category: reports written by security personnel about an incident or condition at a site, carrying a normalized incident type beside the reporting organization's own.
#### Objects
- Added `portal`, `physical_credential`, `alarm_point`, `signal_code`, `post`, `checkpoint`, `patrol_tour`, `response_resource`, and `disposition_details` objects for the Physical Security classes.
#### Dictionary Attributes
- Added the shared attributes of the Physical Security base class: `lifecycle_id`/`lifecycle`, `derivation_id`/`derivation`, `urgency_id`/`urgency`, `certainty_id`/`certainty`, `response_type_id`/`response_type`, `confidence_pct`, and `signal_code`.
- Added `incident_type_id` as an `integer_t` enum of 25 common incident types plus Unknown (0) and Other (99), `incident_type` as its `string_t` sibling, and `incident_type_internal` for the reporting organization's own type.
- Added the class and object attributes: `portal`, `portal_type_id`/`portal_type`, `portal_mode`, `portal_physical_state`, `held_open_duration`, `is_antipassback_violated`; `physical_credential`, `credential_type_id`/`credential_type`, `credential_status`; `alarm_point`, `sensor_type`, `sia_dc03_code`, `contact_id_code`, `contact_id_qualifier`, `onvif_topic`, `osdp_reply`, `native_type`; `disposition_details`, `validation_level_id`/`validation_level`, `verification_method_id`/`verification_method`, `cause_id`/`cause`, `time_to_triage`, `time_to_resolution`; `patrol_tour`, `checkpoint`, `checkpoint_count`, `checkpoint_expected_count`, `checkpoint_token_type`, `is_out_of_sequence`, `geofence_status`, `position_accuracy`, `variance`; `post`, `post_type_id`/`post_type`, `scheduled_start_time`, `scheduled_end_time`, `is_billable`; `response_resource`, `resource_type_id` (with the existing `resource_type` as its sibling), `assigned_time`, `enroute_time`, `on_scene_time`, `cleared_time`, `dispatch_outcome_id`/`dispatch_outcome`; `narrative`, `nibrs_offense_code`, `apco_incident_type`, `is_reportable`, `loss_amount`.
